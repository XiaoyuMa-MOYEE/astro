本文用于记录站点的主要配置入口。所有配置集中在 `src/config.ts`，修改后开发服务器会自动刷新。

## 站点基础信息

`siteConfig` 控制站点名称、副标题、语言、主题、横幅、目录、图标和分享图片。

```ts
export const siteConfig = {
  title: "站点名称",
  subtitle: "站点简介",
  lang: "zh_CN",
  supportedLangs: ["zh_CN", "en"],
  theme: {
    hue: 75,
    mode: "light",
  },
};
```

- 默认语言不带路径前缀，中文首页为 `/`。
- 英文页面使用 `/en/` 前缀。
- `hue` 的范围是 `0–360`。
- `supportedLangs: []` 会关闭语言切换器。

## 导航栏

`navBarConfig.links` 决定顶部导航的顺序。内置页面使用 `LinkPreset`，外部链接使用对象配置。

```ts
links: [
  LinkPreset.Home,
  LinkPreset.Archive,
  LinkPreset.Tools,
  LinkPreset.About,
  LinkPreset.Friends,
  {
    name: "GitHub",
    url: "https://github.com/",
    external: true,
  },
];
```

## 图片路径

- `assets/images/example.jpg` 指向 `src/assets/images/example.jpg`。
- `/media/images/example.jpg` 指向 `public/media/images/example.jpg`。
- 文章中的 `./cover.jpg` 指向 Markdown 文件旁边的图片。

## 个人资料与版权

`profileConfig` 控制头像、昵称、简介和社交链接；`licenseConfig` 控制文章底部的许可协议。

图标名称可在 [Icones](https://icones.js.org/) 查询。使用新的图标集合时，需要安装对应的 `@iconify-json` 包。

## 评论

评论由 Giscus 提供。使用前应在 [giscus.app](https://giscus.app/) 为自己的公开仓库生成配置，并替换：

- `repo`
- `repoId`
- `category`
- `categoryId`

## 分析与部署

`analyticsConfig` 用于启用 Google Analytics 4。`deployConfig.siteUrl` 必须设置为正式域名，因为它会用于 canonical、RSS、站点地图和社交分享链接。

部署在域名根目录时使用：

```ts
baseUrl: "/";
```

部署到仓库子目录时使用：

```ts
baseUrl: "/仓库名/";
```
