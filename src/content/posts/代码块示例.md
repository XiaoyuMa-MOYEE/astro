## 基础语法高亮

在三个反引号后添加语言名称：

````markdown
```js
console.log("你好，世界");
```
````

```js
console.log("你好，世界");
```

## 文件名与终端框架

````markdown
```ts title="src/example.ts"

```sh frame="terminal"

````

## 行标记

使用 `{数字}` 高亮整行，使用 `"文字"` 高亮指定内容：

````markdown
```js {2} "重要内容"
const first = "普通内容";
const second = "重要内容";
```
````

## 增删标记

````markdown
```diff
- const oldValue = true;
+ const newValue = true;
```
````
