# 一级标题

普通段落之间保留一个空行。文字可以使用 **粗体**、*斜体*、~~删除线~~ 和 `行内代码`。

## 列表

- 无序列表项目
- 另一个项目

1. 有序列表第一项
2. 有序列表第二项

## 引用

> 这是引用内容。
>
> 引用可以包含多个段落。

## 链接与图片

```markdown
[Astro 官网](https://astro.build/)
![图片说明](/media/images/example.jpg)
```

文章旁边的图片可以写成：

```markdown
![封面](./cover.jpg)
```
